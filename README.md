# VojnovicSpasoje.github.io

Site root. Its only job: `.well-known/assetlinks.json`, which lets Android open GotGotNeed swap links
(`https://vojnovicspasoje.github.io/gotgotneed/#t=…`) directly in the GotGotNeed app.
The app itself lives in the `gotgotneed` repository. When the Play version is set up, add the
Play App Signing SHA-256 fingerprint to `sha256_cert_fingerprints`.
